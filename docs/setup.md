# STB / C-CAS 読取 → 既存顧客ページで印刷　セットアップ手順

## しくみ

```
[現場スマホ] index.html（GitHub Pagesで配信）
   顧客番号・STB・C-CAS を読み取って「送信」
        │
        ▼
[Googleスプレッドシート] gas/Code.gs（中継）
   顧客番号ごとに番号を保存
        │
        ▼
[事務所PC] 既存の顧客システム ＋ Tampermonkey（userscript/kiki-sashikomi.user.js）
   顧客ページを開くと右下にパネル → 「取得」で機器欄とバーコードが差し込まれる → 「この画面ごと印刷」
```

既存システムには一切手を加えません。PCのブラウザ上で表示を足すだけです。

---

## 1. 中継（gas/Code.gs）を用意する ― 10分

1. Googleドライブで新しいスプレッドシートを作る（名前は例「機器読取ログ」）。
2. ［拡張機能］→［Apps Script］を開き、中身を消して `Code.gs` を貼り付ける。
3. ［プロジェクトの設定］（歯車）→［スクリプト プロパティを追加］で、プロパティ `TOKEN`、値に推測されにくい合言葉（英数字20文字程度）を入れて保存する。合言葉はコードに書きません。
4. ［デプロイ］→［新しいデプロイ］→ 種類の歯車から「ウェブアプリ」。
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**全員**
5. 初回は権限の確認が出るので許可する。
6. 表示された **ウェブアプリURL**（`https://script.google.com/macros/s/…/exec`）を控える。

> コードを直したときは［デプロイを管理］→ 鉛筆 →「新バージョン」で更新すると、URLは変わりません。

## 2. スマホ用ページ（index.html）を公開する

1. GitHubのリポジトリで［Settings］→［Pages］→ Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存。
2. 数分後に `https://test90654.github.io/stb-ccas-scan-print/` で開けるようになります（HTTPSなのでカメラが使えます）。
3. 各スマホで一度だけ、ページ下の「接続設定」に中継URLと合言葉を入れて保存。値はそのスマホの中にだけ保存されます。
4. ホーム画面に追加しておくと便利です。

## 3. 事務所PCにユーザースクリプトを入れる

1. Chrome / Edge に拡張機能 **Tampermonkey** を入れる。
   - Chrome の場合は拡張機能の設定で「ユーザースクリプトを許可」をオンにする必要があります。
2. Tampermonkey の「新規スクリプト作成」に `userscript/kiki-sashikomi.user.js` を貼り付ける。
3. 次の箇所を **Tampermonkey上で** 書き換えて保存する（書き換えた内容はリポジトリに戻さない）。

| 項目 | 書く内容 |
|---|---|
| `@match` | 顧客システムのURL。例 `https://crm.example.co.jp/customer/*` |
| `GAS_URL` / `TOKEN` | 手順1で控えた値 |
| `CUST_NO_SELECTOR` | 顧客番号が入っている要素（下記参照）。空なら画面の文字から「顧客番号：xxxx」を探します |
| `PRINT_PAGE_URL` | 「基本情報印刷」で開くページ。ここでは自動で差し込みます |
| `CUST_NO_URL_PARAM` | 顧客番号が入っているURLのパラメータ名 |
| `INSERT_AFTER_SELECTOR` | 機器欄を入れたい位置。空ならページ末尾 |
| `HIDE_ON_PRINT` | 印刷時に消したいメニューやボタン類 |

### セレクタの調べ方
顧客ページで顧客番号の上を右クリック →［検証］。表示されたタグに `id="…"` があれば `#その値`、`class="…"` なら `.その値` を書きます。分からなければ、その部分のスクリーンショットを送ってもらえれば設定値を作ります。

## 4. 日々の使い方

**現場（スマホ）**
1. 顧客番号を入れる（作業指示書にバーコードがあれば「読取」で可）。
2. STB → C-CAS の順に「読取」。1台読むと次の行へ自動で進みます。2台目以降は「＋ STB/C-CAS 1組」。
3. 「送信」。電波がないときは端末に保存され、あとで「再送」できます。

**事務所（PC）**
1. 既存システムでその顧客のページを開き、いつもどおり「基本情報印刷」を押す。
2. 開いた印刷用ページの下に、最新の機器欄（番号＋バーコード）が自動で入る。
   同じ顧客に複数回の送信があるときは、右下のパネルでほかの回にもチェックを入れられます。
3. いつもどおり「画面印刷」を押す。

> 印刷画面の「詳細設定」で **「ヘッダーとフッター」のチェックを外す**こと。外さないと、ログイン情報入りのURLが紙に印字されます。

## 注意点

- このリポジトリは公開されています。中継URL・合言葉・顧客システムのURLはリポジトリに書かないでください。
- 中継URLと合言葉を知っている人は読取データを見られます。漏れた場合はスクリプト プロパティの `TOKEN` を変えれば、古い合言葉は使えなくなります（再デプロイ不要）。各スマホの接続設定も新しい合言葉に変えてください。
- C-CAS番号は20桁の数字として扱い、印刷時は4桁ずつ区切ります。シートでは文字列で保存するので、桁が欠けることはありません。
- 印刷結果のレイアウトは既存ページの印刷用スタイルに左右されます。機器欄が2ページ目に送られる場合は、`HIDE_ON_PRINT` で不要部分を消して調整します。
